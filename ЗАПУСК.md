# Запуск стартового проекта

Одностраничный лендинг конференции — без сервера и без сборки.

## Как запустить

Откройте `index.html` двойным щелчком (или File → Open в браузере).

## Что нужно сделать

Переработать вёрстку и стили (`style.css`, при необходимости разметку
в `index.html`), ориентируясь на референс (`REFERENCE.md`), **не
меняя логику** в `script.js`: обратный отсчёт до даты мероприятия и
форма регистрации должны продолжать работать как есть.

Файлы:

- `index.html` — разметка экрана (шапка со счётчиком, о мероприятии, программа, билеты, регистрация, контакты)
- `style.css` — стили (основное поле для доработки)
- `script.js` — логика (обратный отсчёт, отправка формы регистрации) — трогать не обязательно
- `REFERENCE.md` — описание желаемого результата
